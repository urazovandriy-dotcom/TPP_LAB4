# Контракт бібліотеки FileComparator (Студент Б, Варіант 14)

## Опис API
Бібліотека призначена для порівняння та аналізу текстових файлів.
Побудована за стандартом C-ABI (`extern "C"`), сумісна як з явним (`LoadLibrary`), так і з неявним зв'язуванням.

### 1. `int CompareFiles(const char* path1, const char* path2)`
* **Призначення:** перевірка файлів на повну ідентичність.
* **Вхідні дані:** валідні рядки шляхів до файлів.
* **Значення, що повертаються:**
  * `1` — файли повністю ідентичні;
  * `0` — вміст файлів відрізняється;
  * `-1` — передано `nullptr`, порожній рядок або файл не вдалося відкрити.

### 2. `int GetCommonWords(const char* path1, const char* path2, char* outBuffer, int bufferSize)`
* **Призначення:** пошук спільних слів без повторів.
* **Вхідні дані:** шляхи до файлів, покажчик на виділений буфер пам'яті `outBuffer`, розмір буфера `bufferSize`.
* **Значення, що повертаються:** кількість знайдених слів або `-1` у разі некоректних аргументів. Буфер заповнюється словами через пробіл.

### 3. `double GetSimilarity(const char* path1, const char* path2)`
* **Призначення:** обчислення коефіцієнта схожості Жаккара.
* **Вхідні дані:** шляхи до файлів.
* **Значення, що повертаються:** число від `0.0` до `1.0`; `-1.0` у разі помилки або неіснуючих файлів.

### 4. `int GetDifferenceCount(const char* path1, const char* path2)`
* **Призначення:** підрахунок кількості відмінних рядків.
* **Вхідні дані:** шляхи до файлів.
* **Значення, що повертаються:** кількість рядків або `-1` у разі збою.

## Гарантії контракту та Edge Cases
* Усі функції гарантовано не викликають неперехоплених винятків, Access Violation або падіння програми (Crash).
* Будь-який `nullptr` чи порожній шлях опрацьовується поверненням кодів `-1` або `-1.0`.
