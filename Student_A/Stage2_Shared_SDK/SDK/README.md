# Контракт бібліотеки TextAnalyzer (Студент А, варіант 14)

**Версія API:** 1.0

Бібліотека для аналізу текстових файлів: частота слів і символів, кількість рядків, найчастіші слова, пошук слова.

## Склад SDK

| Папка | Файл | Для чого |
|---|---|---|
| `include` | `TextAnalyzerDLL.h` | оголошення функцій (для неявного зв'язування) |
| `lib` | `TextAnalyzerDLL.lib` | бібліотека імпорту (для неявного зв'язування) |
| `bin` | `TextAnalyzerDLL.dll` | сама бібліотека, потрібна завжди — кладеться поруч з `.exe` |

DLL зібрана під Windows x64 у Visual Studio (MSVC), конфігурація Release. Програма, яка її підключає, теж має бути x64.

## Загальні правила

- Усі функції мають C-інтерфейс (`extern "C"`), тому їхні імена в DLL не змінені: `WordFrequency`, `CharacterFrequency`, `LineCount`, `TopWords`, `SearchWord`. Їх можна шукати через `GetProcAddress` саме за цими назвами.
- `path` — шлях до файлу, звичайний рядок `const char*`. Шлях краще писати латиницею: якщо в ньому є кирилиця, файл може не відкритися, і функція поверне `-2`.
- Файл читається як текст у кодуванні UTF-8 (або ASCII). Параметри `word` і `symbol` теж мають бути в UTF-8. Якщо слово з кирилицею записане прямо в коді програми, її треба компілювати з ключем `/utf-8` (у CMake: `add_compile_options(/utf-8)`), інакше функція поверне `-1`.
- **Слово** — це підряд записані латинські букви, цифри або кириличні букви. Усе інше (пробіли, розділові знаки, апостроф, дефіс) розділяє слова. Наприклад, `C++` дає слово `c`, а `п'ять` — два слова `п` і `ять`.
- Слова порівнюються **без урахування регістру** — і для латиниці, і для кирилиці: `Привіт` = `привіт`, `CMake` = `cmake`.
- Функції тільки читають файл і нічого в ньому не змінюють.
- Функції незалежні: їх можна викликати в будь-якому порядку і скільки завгодно разів. Нічого ініціалізувати чи закривати не треба — кожна функція сама відкриває і закриває файл.
- Бібліотека не виділяє пам'ять для програми-клієнта, тому нічого звільняти не потрібно. Буфер для `TopWords` виділяє і звільняє сама програма-клієнт.
- Функції не кидають винятків назовні і не завершують програму аварійно при `nullptr` чи неправильних даних — у таких випадках повертається код помилки.

## Коди повернення

| Значення | Що означає |
|---|---|
| `>= 0` | успіх, це і є результат |
| `-1` | неправильні параметри: `nullptr`, порожній рядок, `n <= 0`, `bufferSize <= 0`, у `word` не одне слово, у `symbol` не один символ |
| `-2` | файл не вдалося відкрити (його немає або немає доступу) |

## Функції

### 1. `int WordFrequency(const char* path, const char* word)`
- **Що робить:** рахує, скільки разів слово `word` трапляється у файлі.
- **`word`:** рівно одне слово, наприклад `"привіт"` або `"CMake"`. Регістр не важливий.
- **Повертає:** кількість (`0`, якщо слова немає) або `-1` / `-2`.

### 2. `int CharacterFrequency(const char* path, const char* symbol)`
- **Що робить:** рахує, скільки разів символ трапляється у файлі.
- **`symbol`:** рядок рівно з одного символу UTF-8, наприклад `"a"`, `"т"`, `"!"`. Тут регістр **враховується**: `"Т"` і `"т"` — різні символи.
- **Повертає:** кількість або `-1` / `-2`.

### 3. `int LineCount(const char* path)`
- **Що робить:** рахує рядки у файлі.
- Порожній файл — `0` рядків. Останній рядок без переходу на новий рядок теж рахується.
- **Повертає:** кількість рядків або `-1` / `-2`.

### 4. `int TopWords(const char* path, int n, char* outBuffer, int bufferSize)`
- **Що робить:** знаходить `n` найчастіших слів.
- **`outBuffer`:** масив `char`, куди записується результат; **`bufferSize`** — його розмір у байтах.
- **Формат результату:** рядки `слово кількість`, кожен закінчується `\n`, від найчастішого слова. Слова записуються малими літерами. При однаковій кількості слова йдуть за кодами символів: спочатку цифри, потім латиниця, потім кирилиця (букви `ґ`, `є`, `і`, `ї` стоять після `я`). В кінці стоїть `'\0'`.
- Якщо всі слова не вміщаються в буфер, записуються тільки ті рядки, що вміщаються **повністю** — обрізаних слів не буває.
- **Повертає:** скільки слів записано (може бути менше `n`, якщо слів у файлі менше або не вистачило місця) або `-1` / `-2`. Якщо `outBuffer` не `nullptr` і `bufferSize > 0`, то при помилці в буфері буде порожній рядок.
- Буфера на 1024 байти вистачає приблизно на 40 слів.

### 5. `int SearchWord(const char* path, const char* word)`
- **Що робить:** шукає перший рядок, у якому є слово `word`.
- **`word`:** рівно одне слово, регістр не важливий.
- **Повертає:** номер рядка (рахуємо з `1`), `0` — якщо слова немає, або `-1` / `-2`.

## Неявне підключення (через `.h` і `.lib`)

```cpp
#include "TextAnalyzerDLL.h"

int lines = LineCount("text.txt");
```

У `CMakeLists.txt` треба додати папку `include`, підключити `lib/TextAnalyzerDLL.lib` і скопіювати `bin/TextAnalyzerDLL.dll` поруч з `.exe`.

## Явне підключення (тільки `.dll`)

```cpp
#include <windows.h>
#include <iostream>

typedef int (*LineCountFunc)(const char*);

HMODULE lib = LoadLibrary(TEXT("TextAnalyzerDLL.dll"));
if (lib)
{
    LineCountFunc lineCount = (LineCountFunc)GetProcAddress(lib, "LineCount");
    if (lineCount)
        std::cout << lineCount("text.txt");
    FreeLibrary(lib);
}
```
